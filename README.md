# ArcOS Desktop Presets

## EN

ArcOS Desktop Presets is a fork of [linexin-desktop-presets](https://github.com/Petexy/linexin-desktop-presets). This app have themes to Plasma and GNOME. 

### WARNING
I actually work to have themes for cinnamon and hyprland and they aren't ready yet, that is why the widget will not work with these two desktop environments.

### Dependencies:
- python-gobject
- gtk4
- libadwaita
- python
- arc-center
